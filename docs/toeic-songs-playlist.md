# 🎧 Tạo playlist từ các bài hát chứa từ TOEIC

> 8900 bài hát (đã bỏ trùng) từ trang [🎤 Từ vựng TOEIC trong lời bài hát](toeic-songs-lyrics.md), chia mỗi file 200 bài, theo đúng thứ tự từ vựng trên trang (phần ETS: từ hay gặp trước).

## Cách tạo playlist (Spotify / YouTube Music / Apple Music)

1. Mở một file bên dưới, **chọn hết và copy** (mỗi dòng: `Ca sĩ - Tên bài`).
2. Vào [tunemymusic.com](https://www.tunemymusic.com/) → chọn nguồn **Free text** → dán vào (hoặc [Soundiiz](https://soundiiz.com/) → *Import playlist* → *From text*).
3. Chọn đích **Spotify / YouTube Music / Apple Music**, đăng nhập, bấm chuyển — công cụ tự tìm từng bài và tạo playlist.

> Bản miễn phí thường giới hạn ~500 bài mỗi lần nên chia file 200 bài. Vài bài ít phổ biến có thể không tìm thấy.
