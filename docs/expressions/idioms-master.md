## Work and business

### IDIOM-0001 · get the ball rolling

| | |
|---|---|
| Loại | Idiom · Work and business |
| Nghĩa tiếng Việt | khởi động, bắt đầu một việc |
| Plain English | to start an activity or process so that it continues |
| Chức năng giao tiếp | Đề nghị mọi người bắt tay vào việc; mở đầu cuộc họp, dự án. |
| Ngữ pháp | get + the ball + rolling (V-ing làm bổ ngữ cho tân ngữ: làm cho quả bóng lăn). Hay đi với: get the ball rolling on + N / by + V-ing. Biến thể: start / set the ball rolling (Anh-Anh hay dùng set). |
| Kết hợp hay gặp | get the ball rolling on the project · let's get the ball rolling · get the ball rolling by + V-ing |
| Văn phong · tần suất · CEFR | neutral–informal · common · B2 |
| Ưu tiên | P1 |
| Lỗi người Việt hay mắc | Nói “get the ball roll” (thiếu -ing) hoặc “make the ball rolling”. Đúng: get the ball rolling. |
| Cụm gần nghĩa & khác biệt | kick off (bắt đầu sự kiện/cuộc họp, trang trọng hơn chút); get started (trung tính, không hình ảnh). |
| Trái nghĩa | put something on hold; drag one's feet (chần chừ) |
| Anh-Mỹ / Anh-Anh | Anh-Anh hay nói “set the ball rolling”. |
| Nguồn & bằng chứng | ✅ Có trong phụ đề phim: 2 lượt thoại (Friends 1, The Office 1). Câu thoại thật: “Just to get the ball rolling and to make myself feel better.” — Friends S02E06 / “Maybe... maybe I could get the ball rolling.” — The Office S09E14 |

- **Đời thường (Mỹ)** *(câu tự soạn)*: Let's order pizza and get the ball rolling on this party.
- **Công việc / QA** *(câu tự soạn)*: I'll send out the kickoff email to get the ball rolling on the test plan.
- **IELTS** *(câu tự soạn)*: To get the ball rolling, the government could offer small grants to start-ups.

### IDIOM-0002 · be on the same page

| | |
|---|---|
| Loại | Idiom · Work and business |
| Nghĩa tiếng Việt | cùng hiểu một vấn đề, thống nhất |
| Plain English | to agree or share the same understanding |
| Chức năng giao tiếp | Kiểm tra/khẳng định mọi người hiểu giống nhau trước khi làm. |
| Ngữ pháp | be + on the same page (+ about/with + N). Dùng “on” vì hình ảnh mọi người cùng mở đến một trang sách. Hay ở dạng câu hỏi xác nhận: Are we on the same page? |
| Kết hợp hay gặp | make sure we're on the same page · get everyone on the same page · on the same page about the scope |
| Văn phong · tần suất · CEFR | neutral · very common · B2 |
| Ưu tiên | P1 |
| Lỗi người Việt hay mắc | Dùng “in the same page” (sai giới từ). |
| Cụm gần nghĩa & khác biệt | see eye to eye (đồng quan điểm, thường dùng phủ định); be aligned (công sở, trang trọng hơn). |
| Trái nghĩa | be at odds; be on different pages |
| Nguồn & bằng chứng | ✅ Có trong phụ đề phim: 10 lượt thoại (The Office 6, Silicon Valley 3, Friends 1). Câu thoại thật: “I just want to make sure we're on the same page.” — Friends S02E21 / “It sounds like the two of you are on the same page about that.” — Silicon Valley S05E08 / “Because we're usually not on the same page.” — The Office S06E14 |

- **Đời thường (Mỹ)** *(câu tự soạn)*: Before we book anything, let's make sure we're on the same page about the budget.
- **Công việc / QA** *(câu tự soạn)*: Can we sync quickly so dev and QA are on the same page about the acceptance criteria?
- **IELTS** *(câu tự soạn)*: Parents and teachers need to be on the same page if children are to learn good habits.

## Success and failure

### IDIOM-0003 · a blessing in disguise

| | |
|---|---|
| Loại | Idiom · Success and failure |
| Nghĩa tiếng Việt | trong cái rủi có cái may |
| Plain English | something that seems bad at first but turns out to be good |
| Chức năng giao tiếp | Nhìn lại một chuyện xui hóa ra có lợi; an ủi. |
| Ngữ pháp | be + a blessing in disguise. Thường đi với: turn out to be / prove to be a blessing in disguise. “in disguise” = được ngụy trang. |
| Kết hợp hay gặp | turn out to be a blessing in disguise · prove a blessing in disguise |
| Văn phong · tần suất · CEFR | neutral · common · B2 |
| Ưu tiên | P1 |
| Lỗi người Việt hay mắc | Thiếu mạo từ “a” hoặc nói “blessing in disguised”. |
| Cụm gần nghĩa & khác biệt | every cloud has a silver lining (tục ngữ, chung chung hơn); a lucky break (may mắn, không có ý ban đầu là xui). |
| Trái nghĩa | a curse in disguise (ít dùng); a poisoned chalice (Anh-Anh: tưởng tốt hóa xấu) |
| Nguồn & bằng chứng | ✅ Có trong phụ đề phim: 1 lượt thoại (The Office 1). Câu thoại thật: “It's a blessing in disguise.” — The Office S03E07 |

- **Đời thường (Mỹ)** *(câu tự soạn)*: Missing that flight was a blessing in disguise — I met my wife at the airport.
- **Công việc / QA** *(câu tự soạn)*: Losing that client turned out to be a blessing in disguise; we finally fixed our process.
- **IELTS** *(câu tự soạn)*: Failing my first IELTS test was a blessing in disguise because it made me practise speaking every day.

| | |
|---|---|
| Loại | Idiom · Problem-solving |

| Ngữ pháp | be + (only/just) the tip of the iceberg. Luôn có “the … the”. |

| Văn phong · tần suất · CEFR | neutral · common · B2 |
| Ưu tiên | P1 |
| Lỗi người Việt hay mắc | Bỏ mạo từ: “tip of iceberg”. |
| Cụm gần nghĩa & khác biệt | scratch the surface (mới chạm bề mặt — nói về hiểu biết/công việc, không phải vấn đề). |
| Nguồn & bằng chứng | ✅ Có trong phụ đề phim: 1 lượt thoại (Friends 1). Câu thoại thật: “Tip of the iceberg.” — Friends S09E22 |

- **Đời thường (Mỹ)** *(câu tự soạn)*: The broken window is just the tip of the iceberg — the whole house needs work.

- **IELTS** *(câu tự soạn)*: Reported cases of cyberbullying are probably just the tip of the iceberg.
