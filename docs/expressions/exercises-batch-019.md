# Bài tập đợt 19 *(tự sinh từ các cụm trong đợt)*

Làm trước, rồi mới mở [đáp án](expressions/exercises-batch-019-answers.md).

## A. Việt → Anh (10)

1. Cụm tiếng Anh nào nghĩa là “nhận lời (đề nghị)”? (gợi ý: to accept an offer)
2. Cụm tiếng Anh nào nghĩa là “độ bao phủ kiểm thử”? (gợi ý: how much is tested)
3. Cụm tiếng Anh nào nghĩa là “viết thư/gửi ý kiến”? (gợi ý: to send a letter to an organization)
4. Cụm tiếng Anh nào nghĩa là “bắt chịu trách nhiệm”? (gợi ý: to make someone responsible)
5. Cụm tiếng Anh nào nghĩa là “kiểm thử tiêu cực (dữ liệu sai)”? (gợi ý: testing with invalid inputs)
6. Cụm tiếng Anh nào nghĩa là “cân nhắc”? (gợi ý: to consider carefully)
7. Cụm tiếng Anh nào nghĩa là “thấm dần xuống”? (gợi ý: to spread gradually to lower levels)
8. Cụm tiếng Anh nào nghĩa là “làm rõ, giải quyết”? (gợi ý: to resolve)
9. Cụm tiếng Anh nào nghĩa là “kích hoạt pipeline”? (gợi ý: to start an automated process)
10. Cụm tiếng Anh nào nghĩa là “luồng chạy suôn sẻ (không lỗi)”? (gợi ý: the default scenario with no errors)

## C. Chọn cụm đúng (10)

1. That's ______ — it'll never happen.  
   (an edge case / break the build / expected vs. actual result)
2. The PR has been ______ someone's desk.  
   (take up on / start over / sit on)
3. The ______ got wiped overnight.  
   (triage bugs / test coverage / test data)
4. The test ______ locally but fails on CI.  
   (reproduce a bug / pass / fail / go live)
5. Sorry, my last commit ______.  
   (automate a test / triage bugs / break the build)
6. Bug reports keep ______.  
   (start over / come in / follow on (from))
7. The patch ______ the crash for now.  
   (sift through / stave off / talk up)
8. Please add ______ to the ticket.  
   (reproduce a bug / steps to reproduce / sanity check)
9. Please ______ with screenshots.  
   (root cause / seed the database / file a bug)
10. ______ before running the e2e tests.  
   (push to production / seed the database / root cause)

## D. Viết lại / đặt câu (5)

1. Đặt một câu (về công việc hoặc cuộc sống của bạn) có dùng “go live” — chạy chính thức.
2. Đặt một câu (về công việc hoặc cuộc sống của bạn) có dùng “an edge case” — trường hợp biên.
3. Đặt một câu (về công việc hoặc cuộc sống của bạn) có dùng “sit on” — ngâm (không xử lý).
4. Đặt một câu (về công việc hoặc cuộc sống của bạn) có dùng “run a regression” — chạy kiểm thử hồi quy.
5. Đặt một câu (về công việc hoặc cuộc sống của bạn) có dùng “triage bugs” — phân loại & ưu tiên lỗi.

## E. Nói (5)

1. Nói 45–60 giây về chủ đề “Testing” (đời sống hoặc công việc), dùng: test coverage, negative testing, the happy path.
2. Nói 45–60 giây về chủ đề “Bugs & debugging” (đời sống hoặc công việc), dùng: triage bugs, steps to reproduce, file a bug.
3. Nói 45–60 giây về chủ đề “Release & deployment” (đời sống hoặc công việc), dùng: trigger a pipeline, go live, break the build.
4. Nói 45–60 giây về chủ đề “Communication” (đời sống hoặc công việc), dùng: take up on, write in, straighten out.
5. Nói 45–60 giây về chủ đề “Strategy” (đời sống hoặc công việc), dùng: hold to account, trickle down, stave off.
