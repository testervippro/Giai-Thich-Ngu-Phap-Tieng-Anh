# Đáp án bài tập đợt 20 *(tự sinh từ các cụm trong đợt)*

[← Quay lại đề bài](expressions/exercises-batch-020.md)

## A. Việt → Anh (10)

1. **leave a comment** — IT-EXP-0050 · leave a comment (on sth).
2. **fall over** — IT-EXP-0070 · sth falls over (I).
3. **LGTM** — IT-EXP-0053 · LGTM (viết tắt, chỉ dùng chat/review).
4. **a code freeze** — IT-EXP-0043 · be in a code freeze; a code freeze starts…
5. **a nit** — IT-EXP-0054 · nit: … (tiền tố trong comment).
6. **refactor** — IT-EXP-0055 · refactor sth; a refactor.
7. **bump the version** — IT-EXP-0041 · bump the version (to x.y.z).
8. **under the hood** — IT-EXP-0077 · under the hood.
9. **raise a pull request** — IT-EXP-0047 · raise / open / create a pull request (PR).
10. **check in code** — IT-EXP-0059 · check in code / check sth in.

## B. Điền vào chỗ trống (10)

1. **comment** — IT-EXP-0050 · leave a comment — để lại bình luận
2. **over** — IT-EXP-0070 · fall over — (hệ thống) sập (thân mật)
3. **version** — IT-EXP-0041 · bump the version — tăng số phiên bản
4. **hood** — IT-EXP-0077 · under the hood — bên trong, cơ chế bên dưới
5. **bottleneck** — IT-EXP-0075 · a bottleneck — điểm nghẽn
6. **back** — IT-EXP-0036 · roll back — hoàn tác (bản phát hành)
7. **hotfix** — IT-EXP-0039 · a hotfix — bản vá nóng
8. **done** — IT-EXP-0083 · definition of done — định nghĩa hoàn thành
9. **running** — IT-EXP-0067 · be up and running — hoạt động bình thường
10. **down** — IT-EXP-0061 · spin down — tắt (máy chủ, môi trường)

## C. Chọn cụm đúng (10)

1. **LGTM** — LGTM — trông ổn (duyệt) (câu gốc: LGTM, just one small nit.)
2. **pull the latest** — pull the latest — kéo bản mới nhất (câu gốc: Pull the latest before you rebase.)
3. **run out of memory** — run out of memory — hết bộ nhớ (câu gốc: The job ran out of memory.)
4. **under test** — under test — đang được kiểm thử (câu gốc: Keep the system under test isolated.)
5. **scale out** — scale out — mở rộng ngang (thêm máy) (câu gốc: The service scales out under load.)
6. **go down / be down** — go down / be down — (hệ thống) sập (câu gốc: The staging server is down again.)
7. **out of the box** — out of the box — có sẵn, dùng ngay (câu gốc: Playwright supports parallel runs out of the box.)
8. **a feature flag** — a feature flag — cờ bật/tắt tính năng (câu gốc: The new UI is behind a feature flag.)
9. **in scope / out of scope** — in scope / out of scope — trong / ngoài phạm vi (câu gốc: Mobile testing is out of scope for this release.)
10. **patch** — patch — vá (lỗi) (câu gốc: The vendor patched the vulnerability.)

## D. Viết lại / đặt câu (5)

1. **The database is the bottleneck.** — Câu mẫu (tự soạn). be a bottleneck; identify the bottleneck.
2. **I commented out the failing assertion. (đừng làm vậy!)** — Câu mẫu (tự soạn). comment sth out (T-S).
3. **We rolled back the release after errors spiked.** — Câu mẫu (tự soạn). roll sth back (T-S); danh từ: rollback.
4. **We pushed a hotfix for the payment bug.** — Câu mẫu (tự soạn). push / deploy / release a hotfix.
5. **Tests are part of our definition of done.** — Câu mẫu (tự soạn). meet the definition of done (DoD).

## E. Nói (5)

1. Gợi ý khung: *I left a comment on your photo. / - / -*
2. Gợi ý khung: *- / The new coffee machine is up and running! / -*
3. Gợi ý khung: *- / - / The store rolled back its prices.*
4. Gợi ý khung: *- / - / -*
5. Gợi ý khung: *The kitchen is the bottleneck in this restaurant. / - / -*
