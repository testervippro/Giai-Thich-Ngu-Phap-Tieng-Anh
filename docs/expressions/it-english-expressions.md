## IT

### IT-EXP-0001 · roll out (a feature)

| | |
|---|---|
| Loại | Phrasal Verb · IT |
| Nghĩa tiếng Việt | triển khai, phát hành (dần) tính năng |
| Plain English | to release a product or feature, often gradually |
| Chức năng giao tiếp | Thông báo phát hành/triển khai một tính năng. |
| Ngữ pháp | Ngoại động từ tách được: roll out the update / roll it out (to users). Danh từ: a rollout (staged/phased rollout). Chuẩn trong công nghệ, không phải lóng. |
| Ngoại/nội · tách được? | Ngoại động từ · tách được · cần tân ngữ |
| Kết hợp hay gặp | roll out a feature · roll out to 10% of users · a staged rollout · roll back (hoàn tác) |
| Văn phong · tần suất · CEFR | neutral (tech/business) · common · B2 |
| Ưu tiên | P1 |
| Lỗi người Việt hay mắc | Nhầm với roll back (hoàn tác bản phát hành). |
| Cụm gần nghĩa & khác biệt | launch (ra mắt một lần, ồn ào hơn); deploy (kỹ thuật: đưa code lên môi trường); release. |
| Trái nghĩa | roll back; pull (a feature) |
| Nguồn & bằng chứng | ✅ Có trong phụ đề phim: 10 lượt thoại (Silicon Valley 6, The Office 2, Friends 1, Suits LA 1). Số lần đếm theo mặt chữ, gồm cả nghĩa đen / nghĩa khác của cụm. Câu thoại thật: “You rolled out to your left on a naked bootleg.” — Suits LA S01E13 / “But we'll still be ready to roll out in time for Hoolicon, right?” — Silicon Valley S04E08 / “Really? You think so? You know, I had just rolled right out of bed.” — Friends S07E22 |

- **Đời thường (Mỹ)** *(câu tự soạn)*: The bank is rolling out a new app next month.
- **Công việc / QA** *(câu tự soạn)*: We'll roll out the new checkout flow to 10% of users first.
- **IELTS** *(câu tự soạn)*: The government rolled out the vaccine programme nationwide.

### IT-EXP-0002 · spin up (a server)

| | |
|---|---|
| Loại | Phrasal Verb · IT |
| Nghĩa tiếng Việt | khởi tạo nhanh (máy chủ, môi trường, container) |
| Plain English | to quickly create and start a server or environment |
| Chức năng giao tiếp | Thuật ngữ DevOps/cloud: dựng nhanh tài nguyên. |
| Ngữ pháp | Ngoại động từ tách được: spin up a container / spin it up. Đây là technical jargon — tránh trong văn viết IELTS. |
| Ngoại/nội · tách được? | Ngoại động từ · tách được · cần tân ngữ |
| Kết hợp hay gặp | spin up a server · spin up a test environment · spin up containers · spin down (tắt) |
| Văn phong · tần suất · CEFR | technical jargon / informal workplace · common (in IT) · C1 |
| Ưu tiên | P2 |
| Lỗi người Việt hay mắc | Dùng trong văn viết trang trọng/IELTS. |
| Cụm gần nghĩa & khác biệt | set up (chung); provision (trang trọng, cloud); launch an instance. |
| Trái nghĩa | spin down; tear down |
| Nguồn & bằng chứng | ✅ Có trong phụ đề phim: 2 lượt thoại (Silicon Valley 2). Số lần đếm theo mặt chữ, gồm cả nghĩa đen / nghĩa khác của cụm. Câu thoại thật: “Just spin him up. Please?” — Silicon Valley S04E10 / “He wants me to help spin up this demo” — Silicon Valley S04E03 |

- **Đời thường (Mỹ)** *(câu tự soạn)*: Can you spin up a quick demo for the client?
- **Công việc / QA** *(câu tự soạn)*: The pipeline spins up a fresh Docker container for every test run.
- **IELTS** *(câu tự soạn)*: (Không dùng trong IELTS — thay bằng: set up / create.)

### IT-EXP-0003 · track down (a bug)

| | |
|---|---|
| Loại | Phrasal Verb · IT |
| Nghĩa tiếng Việt | lần ra, truy tìm (sau khi tìm kỹ) |
| Plain English | to find something after a long search |
| Chức năng giao tiếp | Mô tả quá trình truy tìm nguyên nhân lỗi. |
| Ngữ pháp | Ngoại động từ TÁCH ĐƯỢC: track down the bug / track it down. “down” = tới tận nơi, đến cùng. |
| Ngoại/nội · tách được? | Ngoại động từ · tách được · cần tân ngữ |
| Kết hợp hay gặp | track down a bug · track down the root cause · track someone down |
| Văn phong · tần suất · CEFR | neutral · common · B2 |
| Ưu tiên | P1 |
| Lỗi người Việt hay mắc | “track the bug” (thiếu down — nghĩa thành “theo dõi”). |
| Cụm gần nghĩa & khác biệt | hunt down (mạnh hơn); pin down (xác định chính xác); find. |
| Trái nghĩa | lose track of |
| Nguồn & bằng chứng | ✅ Có trong phụ đề phim: 8 lượt thoại (Friends 3, Silicon Valley 2, The Office 2, Suits LA 1). Số lần đếm theo mặt chữ, gồm cả nghĩa đen / nghĩa khác của cụm. Câu thoại thật: “Yeah, uh, you tracked him down. Hold on one second.” — Friends S05E06 / “I'll be able to sneak on and track down whoever ratted me out.” — Silicon Valley S04E09 / “I'm just gonna track down some more chairs.” — The Office S07E07 |

- **Đời thường (Mỹ)** *(câu tự soạn)*: I finally tracked down my old roommate on Facebook.
- **Công việc / QA** *(câu tự soạn)*: It took two days to track down the memory leak.
- **IELTS** *(câu tự soạn)*: Police used CCTV to track down the suspects.
