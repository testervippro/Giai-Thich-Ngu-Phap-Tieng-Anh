## A. Việt → Anh (10)

1. **take up on** — PRO-PHR-0182 · take sb up on an offer.
2. **test coverage** — IT-EXP-0021 · increase / improve / low test coverage.
3. **write in** — PRO-PHR-0190 · write in (to sb).
4. **hold to account** — PRO-PHR-0192 · hold sb to account (for sth).
5. **negative testing** — IT-EXP-0016 · do / perform negative testing.
6. **weigh up** — PRO-PHR-0188 · weigh up sth (T-S).
7. **trickle down** — PRO-PHR-0185 · trickle down (to sb); trickle-down economics.
8. **straighten out** — PRO-PHR-0181 · straighten sth out (T-S).
9. **trigger a pipeline** — IT-EXP-0032 · trigger a pipeline/job/deploy.
10. **the happy path** — IT-EXP-0015 · test the happy path; happy-path scenario.

## B. Điền vào chỗ trống (10)

1. **on** — PRO-PHR-0182 · take up on — nhận lời (đề nghị)
2. **coverage** — IT-EXP-0021 · test coverage — độ bao phủ kiểm thử
3. **in** — PRO-PHR-0190 · write in — viết thư/gửi ý kiến
4. **account** — PRO-PHR-0192 · hold to account — bắt chịu trách nhiệm
5. **testing** — IT-EXP-0016 · negative testing — kiểm thử tiêu cực (dữ liệu sai)
6. **up** — PRO-PHR-0188 · weigh up — cân nhắc
7. **down** — PRO-PHR-0185 · trickle down — thấm dần xuống
8. **out** — PRO-PHR-0181 · straighten out — làm rõ, giải quyết
9. **path** — IT-EXP-0015 · the happy path — luồng chạy suôn sẻ (không lỗi)
10. **live** — IT-EXP-0035 · go live — chạy chính thức

## C. Chọn cụm đúng (10)

1. **an edge case** — an edge case — trường hợp biên (câu gốc: That's an edge case — it'll never happen.)
2. **sit on** — sit on — ngâm (không xử lý) (câu gốc: The PR has been sitting on someone's desk.)
3. **test data** — test data — dữ liệu kiểm thử (câu gốc: The test data got wiped overnight.)
4. **pass / fail** — pass / fail — đạt / trượt (câu gốc: The test passes locally but fails on CI.)
5. **break the build** — break the build — làm hỏng bản build (câu gốc: Sorry, my last commit broke the build.)
6. **come in** — come in — (dữ liệu, kết quả) đổ về; vào (câu gốc: Bug reports keep coming in.)
7. **stave off** — stave off — ngăn chặn (tạm thời) (câu gốc: The patch staved off the crash for now.)
8. **steps to reproduce** — steps to reproduce — các bước tái hiện (câu gốc: Please add steps to reproduce to the ticket.)
9. **file a bug** — file a bug — tạo/báo lỗi (ticket) (câu gốc: Please file a bug with screenshots.)
10. **seed the database** — seed the database — nạp dữ liệu mẫu vào DB (câu gốc: Seed the database before running the e2e tests.)

## D. Viết lại / đặt câu (5)

1. **The new checkout goes live on Monday.** — Câu mẫu (tự soạn). go live (on + date); go-live (danh từ).
2. **Did you test the edge case with an empty cart?** — Câu mẫu (tự soạn). handle / test / cover edge cases.
3. **The PR has been sitting on someone's desk.** — Câu mẫu (tự soạn). sit on sth.
4. **We'll run a full regression before release.** — Câu mẫu (tự soạn). run (a) regression; regression testing; regression suite.
5. **We triage new bugs every morning.** — Câu mẫu (tự soạn). triage + bugs/issues; bug triage (danh từ).

## E. Nói (5)

1. Gợi ý khung: *- / - / -*
2. Gợi ý khung: *- / - / I filed a complaint with the landlord.*
3. Gợi ý khung: *- / The new website goes live tomorrow. / -*
4. Gợi ý khung: *I might take you up on that offer. / Lots of viewers wrote in. / Let's straighten this out.*
5. Gợi ý khung: *We must hold them to account. / The news trickled down to us. / A snack staved off my hunger.*
