# Đáp án bài tập đợt 21 *(tự sinh từ các cụm trong đợt)*

[← Quay lại đề bài](expressions/exercises-batch-021.md)

## A. Việt → Anh (10)

1. **assertion** — IT-EXP-0115 · add / fail an assertion; assert that…
2. **heads-up** — IT-EXP-0094 · give sb a heads-up (about sth); Just a heads-up, …
3. **be behind schedule** — IT-EXP-0092 · be / fall behind schedule.
4. **on call** — IT-EXP-0102 · be on call; on-call rotation.
5. **go/no-go** — IT-EXP-0125 · a go/no-go decision/meeting.
6. **downtime** — IT-EXP-0127 · zero downtime; scheduled downtime.
7. **FYI** — IT-EXP-0095 · FYI, … (viết tắt).
8. **a stack trace** — IT-EXP-0132 · attach / paste the stack trace.
9. **take this offline** — IT-EXP-0098 · Let's take this offline.
10. **won't fix** — IT-EXP-0106 · mark (a bug) as won't fix.

## B. Điền vào chỗ trống (10)

1. **schedule** — IT-EXP-0092 · be behind schedule — trễ tiến độ
2. **call** — IT-EXP-0102 · on call — trực sự cố
3. **offline** — IT-EXP-0098 · take this offline — bàn riêng sau
4. **fix** — IT-EXP-0106 · won't fix — không sửa (quyết định)
5. **machine** — IT-EXP-0107 · works on my machine — máy tôi chạy được mà (đùa)
6. **track** — IT-EXP-0091 · be on track — đúng tiến độ
7. **pointer** — IT-EXP-0133 · null pointer — con trỏ null
8. **positive** — IT-EXP-0114 · false positive — báo động giả
9. **up** — IT-EXP-0100 · sync up — trao đổi để thống nhất
10. **issue** — IT-EXP-0105 · known issue — lỗi đã biết

## C. Chọn cụm đúng (10)

1. **assertion** — assertion — câu khẳng định (trong test) (câu gốc: The assertion failed on line 42.)
2. **go/no-go** — go/no-go — quyết định phát hành hay không (câu gốc: The go/no-go meeting is at 4 p.m.)
3. **downtime** — downtime — thời gian ngừng hoạt động (câu gốc: We migrated with zero downtime.)
4. **FYI** — FYI — để bạn biết (câu gốc: FYI, the API docs moved.)
5. **brittle** — brittle — dễ vỡ (test) (câu gốc: These UI tests are brittle.)
6. **at risk** — at risk — có nguy cơ (trễ, lỗi) (câu gốc: The release date is at risk.)
7. **troubleshoot** — troubleshoot — xử lý sự cố (câu gốc: Here's how to troubleshoot login errors.)
8. **regression** — regression — lỗi hồi quy (tính năng cũ hỏng) (câu gốc: The update introduced a regression in search.)
9. **prioritize** — prioritize — ưu tiên (câu gốc: Let's prioritize the payment bugs.)
10. **headless** — headless — chạy không giao diện (câu gốc: We run the browser tests headless on CI.)

## D. Viết lại / đặt câu (5)

1. **“It works on my machine.” “Then we'll ship your machine.”** — Câu mẫu (tự soạn). It works on my machine.
2. **Let's bring this up in the retro.** — Câu mẫu (tự soạn). in the retro; sprint retrospective.
3. **The full test suite takes 40 minutes.** — Câu mẫu (tự soạn). run / maintain a test suite.
4. **We're on track for the Friday release.** — Câu mẫu (tự soạn). be on track (for/to + V).
5. **It throws a null pointer when the list is empty.** — Câu mẫu (tự soạn). a null pointer exception (NPE).

## E. Nói (5)

1. Gợi ý khung: *- / - / -*
2. Gợi ý khung: *The train is behind schedule. / - / We're on track to arrive by noon.*
3. Gợi ý khung: *- / - / -*
4. Gợi ý khung: *Thanks for the heads-up about the traffic. / FYI, the shop closes early today. / -*
5. Gợi ý khung: *Doctors are often on call at night. / - / -*
