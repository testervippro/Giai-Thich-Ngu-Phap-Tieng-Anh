# Fixed expressions & conversational chunks

> Thuộc **Idioms, Phrasal Verbs & Natural Expressions Bank** — xem bản tương tác: [🔤 Trang tra cứu + bài tập](tools/expressions-bank.html). Bằng chứng dùng thật lấy từ phụ đề 490 tập phim / video (250.686 lượt thoại). Câu ví dụ đánh dấu *(câu tự soạn)* là câu soạn để học, không phải trích dẫn.


**5 mục** (mục tiêu 200).

## Hedging

### FIX-0001 · as far as I know

| | |
|---|---|
| Loại | Fixed Expression · Hedging |
| Nghĩa tiếng Việt | theo tôi biết thì |
| Plain English | based on the information I have (I might be wrong) |
| Chức năng giao tiếp | Rào đón: đưa thông tin nhưng không cam đoan 100%. |
| Ngữ pháp | Đứng đầu hoặc cuối câu: As far as I know, + clause / …, as far as I know. Phủ định ngắn: Not as far as I know. |
| Kết hợp hay gặp | as far as I know · not as far as I know · as far as I can tell |
| Văn phong · tần suất · CEFR | neutral · very common · B1 |
| Ưu tiên | P1 |
| Lỗi người Việt hay mắc | “As far as I knew” khi nói về hiện tại; “As long as I know” (sai cụm). |
| Cụm gần nghĩa & khác biệt | to the best of my knowledge (trang trọng hơn); as far as I can tell (dựa trên quan sát). |
| Trái nghĩa | I know for a fact that… |
| Nguồn & bằng chứng | ℹ️ Không gặp trong phụ đề sitcom đã dò (thường do văn phong trang trọng / chuyên ngành). Câu ví dụ là câu tự soạn để học. |

- **Đời thường (Mỹ)** *(câu tự soạn)*: As far as I know, the store's open until ten.
- **Công việc / QA** *(câu tự soạn)*: As far as I know, that bug was fixed in the last sprint.
- **IELTS** *(câu tự soạn)*: As far as I know, most universities in Vietnam now offer online courses.

## Transition

### FIX-0002 · that being said / having said that

| | |
|---|---|
| Loại | Fixed Expression · Transition |
| Nghĩa tiếng Việt | nói vậy chứ…, dù vậy… |
| Plain English | despite what I have just said |
| Chức năng giao tiếp | Chuyển ý: thừa nhận một điều rồi đưa ra ý ngược/bổ sung. |
| Ngữ pháp | Đứng đầu câu, có dấu phẩy: That being said, … / Having said that, … (mệnh đề phân từ rút gọn). Có thể đứng sau “But”. |
| Kết hợp hay gặp | that being said, · having said that, · with that being said |
| Văn phong · tần suất · CEFR | neutral · common · B2 |
| Ưu tiên | P1 |
| Lỗi người Việt hay mắc | “That been said”, “Have said that”. |
| Cụm gần nghĩa & khác biệt | however (viết); still / even so (nói); that said (ngắn gọn hơn). |
| Nguồn & bằng chứng | ✅ Có trong phụ đề phim: 8 lượt thoại (The Office 3, Friends 2, Silicon Valley 2, Suits LA 1). Câu thoại thật: “That being said, since there's no cash to buy me out, I propose this.” — Silicon Valley S04E04 / “That said that you don't like me?” — The Office S06E15 / “That said it was...” — Friends S05E09 |

- **Đời thường (Mỹ)** *(câu tự soạn)*: The food was great. That being said, it was way too expensive.
- **Công việc / QA** *(câu tự soạn)*: The release is stable. Having said that, we still need to monitor error rates.
- **IELTS** *(câu tự soạn)*: Technology has many benefits. That being said, it can also isolate people.

## Storytelling

### FIX-0003 · it turns out (that)

| | |
|---|---|
| Loại | Fixed Expression · Storytelling |
| Nghĩa tiếng Việt | hóa ra là |
| Plain English | used when you discover something surprising |
| Chức năng giao tiếp | Kể chuyện/báo một phát hiện bất ngờ. |
| Ngữ pháp | It turns out (that) + clause / It turned out to be + N. Cũng có: As it turns out, … |
| Kết hợp hay gặp | it turns out that · as it turned out · turned out to be |
| Văn phong · tần suất · CEFR | neutral · very common · B1 |
| Ưu tiên | P1 |
| Lỗi người Việt hay mắc | “It is turned out”; “It turns out to that”. |
| Cụm gần nghĩa & khác biệt | as it happens (tình cờ là); apparently (nghe nói); it emerged that (báo chí, trang trọng). |
| Nguồn & bằng chứng | ✅ Có trong phụ đề phim: 158 lượt thoại (The Office 65, Friends 54, Silicon Valley 20, Suits LA 19). Câu thoại thật: “The cat turned out to be Paolo's cat. Isn't that funny?” — Friends S01E07 / “It turned out to be nothing more than a panic attack.” — Suits LA S01E05 / “So you know who turned out to be kind of a creep?” — The Office S03E15 |

- **Đời thường (Mỹ)** *(câu tự soạn)*: It turns out he's been married this whole time!
- **Công việc / QA** *(câu tự soạn)*: It turned out the test was failing because of a time zone issue.
- **IELTS** *(câu tự soạn)*: It turns out that children who read for pleasure do better at school.

## Disagreeing

### FIX-0004 · I wouldn't go that far.

| | |
|---|---|
| Loại | Fixed Expression · Disagreeing |
| Nghĩa tiếng Việt | tôi không đến mức nói vậy |
| Plain English | I partly agree, but your statement is too strong |
| Chức năng giao tiếp | Phản đối nhẹ nhàng một nhận định quá đà. |
| Ngữ pháp | I wouldn't go that far (as to say…). Would = giả định lịch sự. |
| Kết hợp hay gặp | I wouldn't go that far · I wouldn't go so far as to say… |
| Văn phong · tần suất · CEFR | neutral · common · B2 |
| Ưu tiên | P1 |
| Lỗi người Việt hay mắc | “I won't go that far” (nghe như từ chối đi xa thật). |
| Cụm gần nghĩa & khác biệt | That's a bit of a stretch; I'm not sure I'd say that. |
| Trái nghĩa | I couldn't agree more. |
| Nguồn & bằng chứng | ℹ️ Không gặp trong phụ đề sitcom đã dò (thường do văn phong trang trọng / chuyên ngành). Câu ví dụ là câu tự soạn để học. |

- **Đời thường (Mỹ)** *(câu tự soạn)*: “That movie was the worst ever.” “I wouldn't go that far.”
- **Công việc / QA** *(câu tự soạn)*: It's slow, but I wouldn't go that far as to call it broken.
- **IELTS** *(câu tự soạn)*: “Social media destroys friendships?” I wouldn't go that far.

## Opinions

### FIX-0005 · at the end of the day

| | |
|---|---|
| Loại | Fixed Expression · Opinions |
| Nghĩa tiếng Việt | rốt cuộc thì, suy cho cùng |
| Plain English | when everything is considered |
| Chức năng giao tiếp | Chốt lại điều quan trọng nhất của một lập luận. |
| Ngữ pháp | Đứng đầu câu: At the end of the day, + clause. Nghĩa đen (cuối ngày) cũng dùng — dựa ngữ cảnh. Dùng vừa phải, lạm dụng nghe sáo. |
| Kết hợp hay gặp | at the end of the day, it's… |
| Văn phong · tần suất · CEFR | informal–neutral · very common · B2 |
| Ưu tiên | P1 |
| Lỗi người Việt hay mắc | Dùng trong IELTS Writing (nên thay: ultimately). |
| Cụm gần nghĩa & khác biệt | ultimately (viết); when all is said and done; all things considered. |
| Nguồn & bằng chứng | ✅ Có trong phụ đề phim: 23 lượt thoại (The Office 17, Friends 4, The Intern 1, Silicon Valley 1). Số lần đếm theo mặt chữ, gồm cả nghĩa đen / nghĩa khác của cụm. Câu thoại thật: “You throw your jacket on a chair at the end of the day.” — Friends S04E06 / “So hang in there, and I will see you at the end of the day.” — The Office S01E03 / “I just knew that at the end of the day...” — The Intern  |

- **Đời thường (Mỹ)** *(câu tự soạn)*: At the end of the day, it's your money.
- **Công việc / QA** *(câu tự soạn)*: At the end of the day, users only care whether it works.
- **IELTS** *(câu tự soạn)*: At the end of the day, education is an investment in the future.
