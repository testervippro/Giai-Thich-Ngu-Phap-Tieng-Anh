## Hedging

### FIX-0001 · as far as I know

| | |
|---|---|
| Loại | Fixed Expression · Hedging |
| Nghĩa tiếng Việt | theo tôi biết thì |
| Plain English | based on the information I have (I might be wrong) |
| Chức năng giao tiếp | Rào đón: đưa thông tin nhưng không cam đoan 100%. |
| Ngữ pháp | Đứng đầu hoặc cuối câu: As far as I know, + clause / …, as far as I know. Phủ định ngắn: Not as far as I know. |
| Kết hợp hay gặp | as far as I know · not as far as I know · as far as I can tell |
| Văn phong · tần suất · CEFR | neutral · very common · B1 |
| Ưu tiên | P1 |
| Lỗi người Việt hay mắc | “As far as I knew” khi nói về hiện tại; “As long as I know” (sai cụm). |
| Cụm gần nghĩa & khác biệt | to the best of my knowledge (trang trọng hơn); as far as I can tell (dựa trên quan sát). |
| Trái nghĩa | I know for a fact that… |
| Nguồn & bằng chứng | ℹ️ Không gặp trong phụ đề sitcom đã dò (thường do văn phong trang trọng / chuyên ngành). Câu ví dụ là câu tự soạn để học. |

- **Đời thường (Mỹ)** *(câu tự soạn)*: As far as I know, the store's open until ten.
- **Công việc / QA** *(câu tự soạn)*: As far as I know, that bug was fixed in the last sprint.
- **IELTS** *(câu tự soạn)*: As far as I know, most universities in Vietnam now offer online courses.
